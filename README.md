# lampa-plugins

Плагины для [Lampa](https://github.com/yumata/lampa-source). Установка: Настройки → Расширения →
Добавить плагин, адрес из раздела плагина.

## Трейлеры Кинопоиска — `kp-trailers.js`

```
https://rufim.github.io/lampa-plugins/kp-trailers.js
```

Пункт «Трейлеры Кинопоиска» в списке кнопки «Смотреть» на карточке фильма или сериала.

- Номер фильма на Кинопоиске берётся из карточки (`kinopoisk_id`), иначе из Wikidata по id TMDB
  или IMDb — без ключей и регистрации.
- Видео — официальный трейлер из плеера-виджета Кинопоиска (`widgets.kinopoisk.ru`), поток HLS
  до 1080p.
- Ниже в списке — трейлеры и тизеры с RuTube (поиск по названию и году, отбор по слову
  «трейлер»/«тизер» в заголовке).
- Плеер по умолчанию внешний (Настройки → Трейлеры Кинопоиска). Долгое нажатие на ролик
  открывает его в другом плеере.

Кинопоиск и RuTube не разрешают запросы из браузера (CORS), поэтому плагин рассчитан на
Android-приложение Lampa: там запросы идут через нативный канал. В веб-версии список будет пуст.
По той же причине встроенный плеер может играть эти потоки только нативным HLS WebView (плагин
снимает с видео `crossorigin` для своих трейлеров). На проекторе с HiSilicon так идёт звук без
картинки — системный плеер рисует видео под окном Lampa, поэтому по умолчанию внешний плеер.

## Выбор парсера — `parser.js`

```
https://rufim.github.io/lampa-plugins/parser.js
```

Пункт «Выбрать парсер» в Настройках → Парсер и кнопка с именем парсера на странице торрентов.
Меню проверяет каждый сервер настоящим поисковым запросом и показывает время ответа и число
раздач. Выбор пишет адрес и ключ в штатные настройки Jackett и сразу перезапускает поиск.
«Свой (из настроек)» возвращает адрес, который был задан до первого выбора.

Серверы (проверены 29.10.2026): Jac-red.ru, Lampa.app, JacRed.su, Jac.red, RU Jac.black,
Freebie (только http), Lampa jacred (только http, ключ 333).

Не ставить вместе с другими плагинами выбора парсера (amikdn, bylampa, pubtorr): они при
старте переписывают те же настройки.

## Фикс звука — `audio-guard.js`

```
https://rufim.github.io/lampa-plugins/audio-guard.js
```

Усыпляет WebAudio (`AudioContext`) на время внешнего плеера.

Открытый `AudioContext` (его, например, держит плагин Modss) не даёт системному микшеру Android
уйти в standby. На приставках вроде SberBox (Amlogic) аудио-HAL в это время не запускает прямой
поток, и битстрим AC3 / E-AC3 / DTS во внешнем плеере (ViMu и т.п.) не идёт: тишина, заикание
или откат на PCM.

Плагин перехватывает `AudioContext`, на запуске внешнего плеера (`Lampa.Android.openPlayer`) или
уходе страницы в фон вызывает `suspend()`, при возврате в Lampa — `resume()`.
